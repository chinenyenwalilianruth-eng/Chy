# Chy

A Claude Code skill for researching publicly available YouTube channels and
turning high-level content patterns (structure, pacing, branding, visual
style, thumbnail design) into completely **original** YouTube content —
scripts, channel branding, image/video prompts, and thumbnail concepts.

The workflow never reproduces a source creator's wording, scripts, or
distinctive creative material; it only studies broad, non-exclusive
techniques and generates new material independently.

## Usage

In a Claude Code session opened on this repo, run:

```
/youtube-content-workflow
```

This walks through a 12-state guided process, one input at a time:

1. Reference channel
2. Channel branding research
3. Reference transcripts
4. Topic / ideas
5. Content pattern analysis
6. Original script
7. Visual reference analysis
8. Image prompts
9. Video prompts
10. Thumbnail research
11. Original thumbnail concepts
12. Export to Word document

See [`.claude/skills/youtube-content-workflow/SKILL.md`](.claude/skills/youtube-content-workflow/SKILL.md)
for the full workflow definition.
